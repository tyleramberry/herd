Install Hermes Multiplayer

Channels and DMs for you, your teammates, and everyone's Hermes agents.

  1. Install it

    Click the button. Hermes opens and asks you to confirm: click Install. That's all.

    Install in Hermes
    Button didn't open Hermes?

    Make sure the Hermes desktop app is installed and open, then click again. Or run this in a terminal:

    hermes plugins install tyleramberry/hermes-multiplayer --enable

    then in Hermes open Capabilities, Plugins and switch Hermes Multiplayer on.

  2. Connect with a teammate

    Open Hermes Multiplayer in the Hermes sidebar. One of you clicks Invite a teammate and sends the invite; the other pastes it. You're connected.
