# N-2 — Demo Narrative Beats (for Herald's H-1 final pass)

Theme: **"Your agent just joined the team."** Every beat must show *collaboration*, not features.

| Beat | Second | What the viewer must feel |
|---|---|---|
| 1. Isolation → connection | 0–5 | Two agents that "have never met" — loneliness of single-player AI made visible in one shot. |
| 2. The one command | 5–15 | Effortlessness: `hermes peer add` typed once, the peer appears in the pane. No config montage. |
| 3. Delegation, not copy-paste | 15–40 | Tyler types a *task* (not a prompt) in a channel; the wife's agent does real work ON HER MACHINE and the result streams into the shared channel. Key emotion: "the work happened somewhere I'm not." |
| 4. Agents talk to each other | 40–55 | Without either human typing, agent B reacts to agent A's output in-channel. The humans watch. This is the beat no other hackathon entry can show. |
| 5. Humans stay in charge | 55–70 | A private DM between Tyler and his wife while agents keep working — multiplayer doesn't mean the bots run the room. |
| 6. Name the thing | 70–85 | "Herd — multiplayer Hermes." Install one-liner + @NousResearch tag. |

**Copy lines to choose from (A/B at rehearsal):**
- Hook A: "This is one agent. This is another. They've never met." (Herald's, keep as default)
- Hook B: "My agent just hired my wife's agent."
- Closer: "Multiplayer Hermes. Herd."

**Do/don't:**
- DO show real latency honestly once; cut the rest tight.
- DON'T show any key, URL with a token, or the admin log on screen — masked constants only.
- DON'T enumerate features in the VO; one sentence at the end is the whole pitch.
- Every beat must survive "so what?" — if a shot doesn't show two parties interacting, cut it.
